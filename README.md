# ETF 量化策略研究

A 股 ETF 量化投资策略回测研究，包含三个独立策略，覆盖趋势跟踪、动量轮动、风险平价三种主流量化方法。

---

## 策略概览

| 策略 | 核心逻辑 | 适合市场 | 回测区间 | 年化收益 | 夏普 | 最大回撤 |
|------|---------|---------|---------|---------|------|---------|
| **双均线交叉** | 快慢均线金叉死叉 + 5 层风控 | 趋势明显的宽基 ETF | 2016-2026 | 3.36% | 0.15 | -5.10% |
| **动量趋势轮动** | 行业 ETF 动量排序 + 120MA 趋势过滤 | 结构市/熊市 | 2021-2026 | +11.5% | 0.40 | -24.9% |
| **全天候风险平价** | 风险等权配置 + HMM 状态感知 | 全天候 | 2017-2026 | 6.79% | 0.65 | -10.88% |

## 1. 双均线交叉策略

基于快慢均线金叉死叉交易宽基 ETF，遍历9个A股宽基指数,15种均线组合,V2 版本增加 5 层风险控制模块。

### V2 风控体系

| 层级 | 机制 | 效果 |
|------|------|------|
| 大盘择时 | 沪深300 MA60 空头禁止开仓 | 减少熊市假信号 |
| 单笔止损 | 亏损 3% 强制平仓 | 截断单笔亏损 |
| ATR仓位 | 波动率高→仓位小 | 风险预算 1% 账户净值 |
| 最大回撤 | 净值回撤 15% 清仓暂停 | 尾部风险控制 |
| 总量风控 | 单 ETF 不超过 30% 仓位 | 集中度限制 |

### V2 vs V1（以中证2000 5x120 为例）

| 指标 | V1（无风控） | V2（有风控） | 变化 |
|------|------------|------------|------|
| 最大回撤 | -32.76% | **-5.10%** | ↓ 大幅降低 |
| 交易成本 | 43,833 元 | 684 元 | ↓↓ 降低 98% |
| 交易次数 | 32 次 | 3 次 | ↓↓ 减少 91% |
| 卡玛比率 | 0.34 | **0.66** | ↑ 风险效率提升 |

### 关键发现

- **风控是双刃剑**：降低回撤的同时也限制了收益空间
- **长周期组合更稳健**：5x120、60x120 信号少但质量高
- **小盘股最优**：中证2000 在趋势策略中表现最好

### 运行方式

```bash
cd 宽基指数ETF双均线策略 && python dual_ma_strategy_v2.py
```

## 2. 动量趋势轮动策略

在 631 只行业/主题 ETF 中按动量信号排序轮动，通过 **沪深300 120日均线趋势过滤** 实现市场环境自适应。

### 核心结果（V2 最佳组合：简单动量_20日_趋势）

| 指标 | v2 策略 | 沪深300基准 | 变化 |
|------|---------|------------|------|
| 年化收益 | +11.5% | -1.7% | +16.8% |
| 夏普比率 | 0.40 | — | — |
| 最大回撤 | 24.9% | — | — |
| 2022 年收益 | +1.78% | -21.63% | 空仓避险成功 |

### 各阶段表现（v4 分阶段分析）

| 市场环境 | 策略表现 | 说明 |
|---------|---------|------|
| 大牛市 (2014-2015) | 弱于基准 | 动量轮动滞后 |
| 流动性危机 (2015) | **完美避险** | 双重动量+趋势过滤全程空仓 |
| 震荡慢牛 (2016-2017) | **致命软肋** | 极速轮动市中全部亏损 |
| 单边熊市 (2018) | 有效控制亏损 | 跑赢基准约 18% |
| 核心资产牛 (2019-2021) | 跑输基准 | 慢牛中仓位过于保守 |
| 结构市 (2021-2026) | **显著超额** | +15.4% 超额收益 |

### 核心结论

- **趋势过滤器是唯一质变优化**：开启后夏普从 -0.80 提升至 -0.13（+0.67）
- **不存在跨周期最优参数**：20日适合快轮动，60日适合慢趋势
- **震荡慢牛市是策略命门**：建议结合市场状态识别动态切换参数

### 运行方式

```bash
cd 动量趋势ETF行业主题轮动策略 && python momentum_rotation_v4.py
```

## 3. 全天候风险平价策略

基于 Bridgewater 达利欧的全天候框架，将经济划分为四大象限，通过 **HRP 层次聚类 + Ledoit-Wolf 协方差收缩 + HMM 市场状态识别 + 200MA 趋势过滤** 实现等风险分配。

### 核心结果（V2）

| 指标 | V2（HRP+HMM） | 经典全天候 | 沪深300 |
|------|--------------|-----------|---------|
| 年化收益率 | 6.79% | 6.69% | 2.41% |
| 年化波动率 | 6.33% | 10.89% | 19.50% |
| 夏普比率 | 0.65 | 0.37 | -0.00 |
| 最大回撤 | -10.88% | -21.49% | -45.10% |

### 关键发现

- **HRP 替代 ERC**：消除权重震荡，无需优化器调试
- **Ledoit-Wolf 收缩**：协方差估计更稳健，换手率降低 15-20%
- **200MA 趋势过滤**：熊市自动减仓，2025/2026 美股跌破 200MA 时成功切换至债券/黄金
- **覆盖完整牛熊**：包含 2018 年下跌和 2022 年调整

### 运行方式

```bash
cd A股ETF模拟全天候策略/V2 && python run_backtest.py
```

## 核心结论汇总

| 策略 | 最有效方法 | 最大风险 | 实盘建议 |
|------|----------|---------|---------|
| 双均线 | ATR 动态仓位 + 大盘过滤 | 收益低于买入持有 | 作为趋势确认工具而非独立策略 |
| 动量轮动 | 120MA 趋势过滤 | 震荡市中反复止损 | 需配合市场状态识别，避免 2016-2017 式行情 |
| 全天候 | HRP + 200MA 趋势过滤 | 美股纳入后波动增大 | 适合追求稳健绝对收益 |
