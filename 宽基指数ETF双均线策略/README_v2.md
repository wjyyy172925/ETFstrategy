# ETF双均线滚动策略回测 V2 — 风险控制增强版

## 策略概述

基于双均线交叉信号的ETF趋势跟踪策略（V1基础），增加5层风险控制模块，测试4只宽基ETF在不同均线组合下的历史表现。

### V2新增风控模块

| 风控层 | 机制 | 参数 |
|--------|------|------|
| 大盘择时过滤 | 沪深300/富时A50 MA60，空头时禁止开仓 | MA60 |
| 单笔止损 | 持仓亏损达3%强制平仓（每天检查，含无信号日） | 3% |
| ATR仓位管理 | ATR(20)动态计算买入股数，波动率高→仓位小 | 风险敞口1% |
| 最大回撤止损 | 净值从高点回撤15%→全仓清仓+暂停交易 | 15% |
| 总量风控 | 单只ETF持仓不超过总资金30% | 30% |

## 关键发现

### 1. 风控显著降低最大回撤

V2的5层风控将最大回撤从ETF本身的-30%~-60%降低至-5%~-8%，策略实际风险大幅下降。中证2000最优组合回撤仅-5.10%。

### 2. ATR仓位管理大幅降低交易成本

ATR动态仓位使单笔交易金额更小，交易成本从V1的4-5万元降至数百至数千元，成本侵蚀几乎可以忽略。

### 3. 大盘择时过滤减少假信号

富时A50作为大盘基准，MA60过滤在熊市期间阻止了大量无效买入，减少了震荡市中的来回止损。

### 4. 收益降低但风险调整后更优

由于仓位更保守（ATR限制+30%上限）+ 大盘过滤，绝对收益较V1有所下降，但卡玛比率（收益/回撤）提升明显，例如中证2000从0.34提升至0.66。

### 5. 回撤止损未触发

在当前4只ETF的回测中，15%最大回撤止损均未触发，说明ATR仓位管理和大盘择时已经有效控制了下行风险。

### 6. 小盘股仍是最优标的

中证2000（563300）在V2中仍表现最优，夏普0.15为唯一正值，年化3.36%。科创50紧随其后。

### 7. 长周期组合更稳健

5x120、60x120等长周期组合在V2中表现更稳健，信号更少但质量更高，配合风控效果更好。

## 策略局限性

1. **收益低于买入持有**：风控降低了风险，但也限制了收益空间
2. **信号滞后**：均线交叉信号存在滞后，可能错过最佳买卖点
3. **震荡市仍会亏损**：虽然风控减少了亏损幅度，但震荡市中仍会产生连续小亏
4. **回撤止损有一天滞后**：日频回测中，盘中回撤可能超过阈值但收盘恢复，次日才触发
5. **未考虑分红**：ETF分红再投资未纳入计算
6. **单一指标**：仅基于均线交叉，未结合成交量、RSI等其他指标
