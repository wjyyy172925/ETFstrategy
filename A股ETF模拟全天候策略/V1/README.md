# A股ETF模拟全天候策略

基于桥水基金 **全天候（All Weather）** 框架的A股风险平价（Risk Parity）策略回测实现。使用A股ETF作为投资标的，通过等风险贡献（ERC）优化实现资产大类间的风险均衡配置，旨在任何宏观环境下都能获得稳健回报。

---

## 策略概述

### 核心理念

全天候策略将经济环境划分为四大象限（增长↑/↓ × 通胀↑/↓），每个象限配置对应受益的资产。通过风险平价实现**等风险分配**——而非等金额分配，使组合在任一宏观经济状态下都有资产贡献收益。

### ETF标的池（6只）

| 资产大类     |风险预算|     ETF   |  代码   |    角色    |
|------------|-------|-----------|--------|------------|
| 权益        | 20%   | 沪深300ETF | 510300 | A股大盘蓝筹 |
|            |       | 中证500ETF | 510500 | A股中盘成长 |
| 长久期利率债 | 20%   | 十年国债ETF | 511260 | 久期≈8年，抗通缩核心 |
| 中短债+信用债| 20%   | 国债ETF    | 511010 | 久期≈4年，稳定现金流 |
| 黄金        | 20%  | 黄金ETF     | 518880 | 抗通胀+避险 |
| 商品        | 20%  | 豆粕ETF     | 159985 | 商品期货跟踪 |

国开债ETF（159649）因2022年才上市，与其它标的时间对齐后数据量过少，已从回测中排除。

### 再平衡机制（三触发器）

1. **日历再平衡**：每月末（`REBALANCE_FREQ = "ME"`）定时触发
2. **阈值偏离**：任一资产实际权重偏离目标超过 ±8% 触发
3. **波动率变化**：组合波动率较上月变化 > 30% 触发

每次再平衡仅执行到目标的80%（`EXECUTION_RATIO = 0.80`），减少摩擦成本。

### 三层风控体系

| 层级      | 风控措施                           | 触发条件                |
|----------|-----------------------------------|------------------------|
| 波动率目标 | 缩放整体敞口，目标年化波动10%，容忍±2% | 预测波动率超出 [8%, 12%] |
| 回撤控制  | 回撤10%→权益降至80%；回撤15%→降至50%  | 当前回撤达预警线          |
| CVaR预警 | CVaR超15%→减仓50%；回撤20%→全仓清仓   | 月频CVaR或最大回撤触发    |

### 交易成本

- 佣金：万0.3（`COMMISSION_RATE = 0.00003`）
- 滑点：0.05%（`SLIPPAGE_RATE = 0.0005`）
- 单边总成本：万8
- 最小交易金额：¥5,000

## 数据与环境要求

### 数据文件

CSV数据文件位于 `data/etf/` 目录，文件名格式为 `{代码}.csv`（如 `510300.csv`）。

必需列（支持中文/英文列名）：

| 英文列名 | 中文列名 | 说明 |
|---------|---------|------|
| `date`  | 日期    | 交易日 |
| `close` | 收盘    | 复权净值（前复权或不复权均可，需一致） |

可选但建议包含：`open`, `high`, `low`, `volume`, `amount` 等。

如果本地CSV数据不足，`data.py` 会自动调用 **akshare** 从东方财富/新浪下载补充。

### Python 环境

- Python 3.8+
- 必需包：`numpy`, `pandas`, `scipy`, `matplotlib`
- 可选包：`akshare`（网络数据下载）

### 安装

```bash
pip install numpy pandas scipy matplotlib
# 如需网络数据回退下载:
pip install akshare
```

## 用法

```bash
cd A股ETF模拟全天候策略
python run_backtest.py
```

### 运行流程

1. 从 `data/etf/` 加载6只ETF的CSV数据
2. 内连接对齐日期（取所有ETF的共同交易日）
3. 逐日运行回测（2019-12-05 ~ 2026-07-22）
4. 计算绩效指标，构建3个对比基准
5. 输出绩效对比表和3面板图表

### 输出

| 文件                       | 说明                             |
|---------------------------|----------------------------------|
| `output/nav.csv`          | 每日组合净值                       |
| `output/weights.csv`      | 每日ETF权重                       |
| `output/performance.png`  | 3面板图表：净值曲线/权重演变/指标对比 |
| `output/logs/backtest.log`| 详细回测日志                       |

## 回测结果

### 核心指标

| 指标      | 全天候(ERC)| 沪深300 | 经典全天候 | 等权重 |
|----------|-----------|---------|-----------|-------|
| 年化收益率 | 5.68%     | 1.62%  | 4.08%     | 4.70% |
| 年化波动率 | 3.06%     | 20.38% | 8.37%     | 9.12% |
| 夏普比率  | 1.01      | 0.04    | 0.26      | 0.31  |
| 最大回撤  | -2.71%    | -39.52% | -8.47%   |-16.06% |
| 卡玛比率  | 2.10      | 0.04    | 0.48      | 0.29  |
| 胜率     | 56.82%    | 52.32%  | 55.01%    | 53.53% |

*回测区间：2019-12-05 ~ 2026-07-22（6.4年，1606个交易日）*
*初始资金：¥100,000,000 → 最终净值：¥142,201,300（1.4220×）*
*总交易次数：397*

### 关键发现

- **最大回撤仅 -2.71%**（2020-03-19，新冠疫情冲击），远低于沪深300的 -39.52%
- **夏普比率 1.01**，是沪深300的25倍，体现出卓越的风险调整后收益
- **卡玛比率 2.10**，每单位回撤对应2.1倍年化收益，收益/风险比最优
- 年化收益5.68%虽不突出，但**波动率仅3.06%**，组合路径非常平滑

## 优势与局限

### 优势

1. **极端低回撤**：即使在2020年新冠疫情、2022年市场大跌中，回撤均控制在3%以内
2. **卓越风险调整收益**：夏普 > 1.0，大幅跑赢所有对比基准
3. **多资产分散**：权益/债券/黄金/商品跨资产配置，非权益资产在股市下跌中提供保护
4. **自动再平衡**：三触发机制确保权重及时回归目标，实现低买高卖
5. **A股落地**：全部使用境内ETF，账户开设和交易无外汇限制

### 局限

1. **绝对收益不高**：5.68%年化收益在牛市中吸引力有限，适合低风险偏好资金
2. **债券仓位过重**：债券类资产（十年国债ETF+国债ETF）合计风险预算50%，在利率上行期承压
3. **无宏观择时**：策略完全依赖风险平价框架，未对宏观经济阶段做主动判断
4. **无法捕捉相关性结构突变**: 比如股债双杀,流动性冲击等
5. **使用固定阈值参数**：8%偏离阈值、30%波动率变化阈值等参数未做敏感性测试
6. **回测区间偏短**：6.4年回测未覆盖完整的利率周期（如2013-2014钱荒）

## 优化方向

| 优先级 | 方向             | 描述                                                        |
|-------|------------------|------------------------------------------------------------|
| 1     | **商品资产扩充**   | 增加更多商品ETF（如能源化工ETF、有色ETF），降低豆粕单一品种的依赖   |
| 2     | **宏观因子择时**   | 引入CPI/PPI、PMI、社融等宏观指标，动态调整大类资产风险预算         |
| 3     | **参数敏感性测试** | 对THRESHOLD_PCT、VOL_WINDOW、CVAR_THRESHOLD等关键参数做网格搜索 |
| 4     | **趋势过滤**      | 在权益资产中加入200日均线过滤，避开明显熊市                       |
| 5     | **动态波动率目标** | 根据VIX-like指标（如50ETF期权隐含波动率）动态调整TARGET_VOL       |
| 6     | **海外资产配置**   | 增加标普500ETF（513500）或纳指ETF（513100），提升组合有效前沿     |
