# A股ETF模拟全天候策略 V2 — HRP + HMM + Ledoit-Wolf

基于桥水 **全天候（All Weather）** 框架的风险平价策略回测实现，V2 引入三项核心优化：

1. **分层风险平价（HRP）** — 替代 SLSQP-ERC，层次聚类+递归二分，解决高相关资产权重震荡
2. **200日均线过滤** — 权益 ETF 跌破 200MA 时自动减仓，规避明显熊市
3. **HMM 市场状态识别** — 3状态 Gaussian HMM 划分牛/熊/震荡，每状态独立 Ledoit-Wolf 收缩协方差

---

## V1 → V2 主要变化

| 维度     | V1               | V2                               |
|----------|-----------------|----------------------------------|
| 权重求解  | ERC（SLSQP 优化） | HRP（层次聚类+递归二分）             |
| 协方差估计| 60日滚动样本协方差 | 状态级 Ledoit-Wolf 收缩协方差        |
| 市场状态  | 无               | 3状态 HMM（高波动熊/低波动震荡/复苏牛）|
| 趋势过滤  | 无               | 200日均线过滤（权益类）              |
| ETF数量  | 6只              | 9只（+标普500/纳指/有色金属ETF）      |
| 回测区间  | 2019-12 ~ 2026-07| 2017-09 ~ 2026-07                |

### HRP 分层风险平价

HRP（Lopez de Prado, 2016）通过层次聚类替代数值优化：

```
协方差矩阵 → 相关系数 → 距离矩阵 → 单链聚类 → 矩阵序列化 → 递归二分赋权
```

- 高相关资产（4 只权益 ETF）自动聚簇，簇内按逆方差分配
- 无优化器，不存在收敛问题，权重天然稳定
- `config.py` 中 `HRP_ENABLED` 可切换回 ERC 回退

### Ledoit-Wolf 收缩协方差

每市场状态使用 Ledoit-Wolf（2004）收缩估计：

```
Σ_lw = δ * F + (1-δ) * S
```

- S = 样本协方差，F = 常量相关目标矩阵
- δ 由数据自动确定，极端行情时 δ 增大，抑制噪声
- 显著降低换手率，平滑权重震荡

### 200日均线过滤

权益 ETF 价格跌破 200MA → 该 ETF 权重归零，预算重分配给其他资产
价格重回均线上方 → 恢复正常配置
可配置 `MA_ASSET_CLASSES` 控制受影响的资产类别

### HMM 市场状态识别

3 状态 Gaussian HMM，每季度重新训练：

| 状态      | 特征         | 协方差来源               |
|----------|--------------|------------------------|
| 高波动熊市 | 低均值+高方差 | 该状态历史收益率的 LW 收缩 |
| 低波动震荡 | 均值≈0+低方差 | 该状态历史收益率的 LW 收缩 |
| 复苏牛市   | 高均值+中方差 | 该状态历史收益率的 LW 收缩 |

状态切换时协方差指数平滑（α=0.5），防止权重跳变。

### 再平衡机制（三触发器）

1. **日历再平衡**：每月末定时触发
2. **阈值偏离**：任一资产偏离目标超过 ±8% 触发
3. **波动率变化**：组合波动率较上月变化 > 30% 触发

每次执行到目标的 80%（`EXECUTION_RATIO = 0.80`）。

### 三层风控体系

| 层级      | 风控措施                              | 触发条件                |
|----------|--------------------------------------|-----------------------|
| 波动率目标 | 缩放整体敞口，目标年化波动 10%           | 预测波动率超出 [8%, 12%] |
| 回撤控制   | 回撤 10%→权益降至 80%；15%→降至 50%    | 当前回撤达预警线          |
| CVaR 预警 | CVaR 超 15%→减仓 50%；回撤 20%→全仓清仓 | 月频 CVaR 或最大回撤触发  |

## 用法

```bash
cd A股ETF模拟全天候策略/V2
python run_backtest.py
```

### 运行流程

1. 加载 9 只 ETF 数据，内连接对齐
2. 逐日运行回测（2017-09-01 ~ 2026-07-22）
3. 计算绩效指标，构建 3 个对比基准
4. 输出绩效对比表和 3 面板图表

### 关键配置开关

| 参数                 | 默认值  | 说明                                     |
|---------------------|--------|------------------------------------------|
| `HRP_ENABLED`       | `True` | HRP 求解；设为 `False` 回退 ERC 优化        |
| `MA_FILTER_ENABLED` | `True` | 200日均线过滤                              |
| `MA_WINDOW`         | `200`  | 均线周期                                   |
| `HMM_ENABLED`       | `True` | HMM 状态识别；设为 `False` 使用全局 LW 协方差 |
| `HMM_N_STATES`      | `3`    | 状态数量                                   |

## 回测结果

### 核心指标

| 指标      | 全天候(HRP+HMM) | 沪深300  | 经典全天候 | 等权重 |
|----------|----------------|---------|-----------|-------|
| 年化收益率 | 6.79%          | 2.41%   | 6.69%     | 5.35% |
| 年化波动率 | 6.33%          | 19.50%  | 10.89%    | 13.83%|
| 夏普比率   | 0.65          | -0.00   | 0.37      | 0.20   |
| 最大回撤   | -10.88%       | -45.10% | -21.49%   | -35.90%|
| 卡玛比率   | 0.62          | 0.05    | 0.31      | 0.15   |
| 胜率      | 55.46%         | 49.74%  | 54.16%    | 55.23% |

*回测区间：2017-09-01 ~ 2026-07-22（~8.9年，2152个交易日）*
*初始资金：¥100,000,000 → 最终净值：¥175,174,518（1.75×）*
*总交易次数：781*

### 关键发现

- **夏普比率 0.65** — 显著领先经典全天候（0.37）和沪深300（-0.00）
- **最大回撤仅 -10.88%** — 同期沪深300回撤 -45.10%
- **200MA 过滤** — 在 2025 年 4 月美股 ETF（513500/513100）跌破 200MA 时自动减仓，有效控制回撤
- **HMM 状态感知** — 状态级 Ledoit-Wolf 协方差在极端行情下自适应收缩，降低权重震荡

## 优势与局限

### 优势

1. **低回撤**：即使在 2022 年 A 股大跌和 2025 年美股调整中，回撤均控制在 11% 以内
2. **高夏普**：0.65 夏普比率大幅跑赢所有对比基准
3. **状态适应**：HMM 自动识别市场状态并切换协方差估计方式
4. **趋势保护**：200MA 过滤在明显熊市中自动降低权益暴露
5. **多资产分散**：中美权益 + 利率债 + 黄金 + 商品，跨市场跨资产

### 局限

1. **换手率偏高**：初期（2017年）阈值再平衡触发频繁，日均触发多日
2. **绝对收益有限**：6.79% 年化在牛市中吸引力有限
3. **HMM 超参数**：状态数、训练窗口、重训频率等参数未做网格搜索优化
4. **交易成本假设**：统一滑点假设未区分 ETF 流动性差异
5. **无汇率对冲**：美股 ETF（513500/513100）含汇率风险

| 方向     | 措施                                 |
|---------|--------------------------------------|
| HMM 优化 | 网格搜索 n_states/window/retrain_freq |

| 成本敏感 | 区分高/低流动性 ETF 的滑点假设           |
| 状态预算 | 不同 HMM 状态使用不同风险预算分配         |
