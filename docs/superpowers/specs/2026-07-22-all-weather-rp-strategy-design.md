# A股ETF模拟桥水全天候策略 — 带约束风险平价版

## 概述

使用A股ETF构建模拟桥水全天候策略的量化策略，采用**带约束的等风险贡献（ERC）风险平价**方式，通过每月再平衡实现各类资产对组合总风险的均衡贡献。

## 策略参数

| 参数 | 值 |
|------|-----|
| 资金规模 | 1亿元 |
| 投资期限 | 5年以上 |
| 风险平价方法 | 带约束等风险贡献（ERC） |
| 约束条件 | 单资产权重 5% ≤ w ≤ 40% |
| 目标年化波动率 | 8-12% |

## 风险平价权重计算

### 目标函数

每月末使用过去60个交易日的日收益率计算各资产的年化波动率，求解以下优化问题：

```
min  Σᵢ Σⱼ (wᵢ·RCᵢ - wⱼ·RCⱼ)²
s.t. Σ wᵢ = 1
     0.05 ≤ wᵢ ≤ 0.40
```

其中 RCᵢ = wᵢ · (Σw)ᵢ / σₚ 为第 i 类资产的边际风险贡献，σₚ 为组合波动率，Σ 为协方差矩阵。

### 计算流程

1. 获取各ETF过去60个交易日收益率序列
2. 计算协方差矩阵
3. 使用 scipy.optimize 求解ERC权重
4. 应用权重上下限约束
5. 若单资产权重触及边界，将其固定在边界值后，在剩余资产中重新分配风险预算

## 再平衡策略

| 项目 | 规则 |
|------|------|
| 定期 | 每月第一个交易日重新计算ERC权重 |
| 阈值触发 | 任一资产偏离目标权重 ±8%，或波动率较上月变化 > 30%，立即触发再平衡 |
| 执行策略 | 每次仅调整到目标权重的80%（减少摩擦成本） |
| 交易成本 | 佣金0.03‰ + 滑点0.05%（ETF免征印花税） |

### 再平衡检查流程

```
每个交易日:
  ├─ 是否每月第1个交易日? ──→ 是 ──→ 计算ERC权重 → 偏离>8%? → 执行80%调整
  └─ 是否触发阈值? ──────→ 是 ──→ 同上
      └─ 否 ──→ 维持
```

## 风控措施

### 波动率管理
- 目标组合年化波动率 **8-12%**
- 滚动20日年化波动率监控
- 超出范围则等比例缩放各资产风险预算

### 尾部风险管理
- 每日计算 VaR(95%) 和 CVaR
- CVaR > 15% 时，全面降仓20%，将释放资金分配至国债ETF

### 最大回撤控制
| 回撤幅度 | 行动 |
|---------|------|
| > 10% | 权益风险预算从25%降至15%，释放资金转至中短债 |
| > 20% | 全仓转为货币ETF/国债ETF，暂停所有风险敞口 |

### 集中度约束
- 单只ETF持仓不超过总资产的 **30%**

### 流动性管理
- 持仓ETF日均成交额 < 5000万则自动剔除，寻找替代标的
- 初始建仓时分3日均价完成，避免冲击成本

### 久期风险管理
- 十年国债ETF(511260)久期 > 7年时，自动将50%仓位切换至国债ETF(511010)

## 绩效指标

| 指标 | 计算方式 |
|------|---------|
| 年化收益率 | 几何年化 |
| 年化波动率 | 日收益率标准差 × √252 |
| 夏普比率 | (年化收益 - 无风险利率) / 年化波动率 |
| 最大回撤 | 净值曲线峰值到谷值最大跌幅 |
| 卡玛比率 | 年化收益率 / 最大回撤绝对值 |
| 风险归因 | 各资产对组合总风险贡献占比 |

## 回测验证方案

1. 使用 `download_etf.py` 下载所选ETF历史数据
2. 使用 akshare 获取 PMI/CPI/PPI/工业增加值用于宏观环境标注
3. 回测期至少覆盖2015年至今（含牛熊周期）
4. 对比基准：沪深300指数、等权重组合、经典30/55/7.5/7.5全天候组合
