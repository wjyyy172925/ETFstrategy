# 动量趋势轮动策略设计文档

## 概述

基于 A 股 ETF 历史日线数据，实现动量趋势轮动策略，自动穷举参数组合并对比绩效。

## 数据来源

- `data/etf/*.csv` — 每只 ETF 的历史日线行情（来源于 akshare 东方财富）
- `data/etf_list.csv` — ETF 列表，包含代码、名称等信息
- 基准使用沪深300 ETF（代码 510300）

## 策略参数组合（自动穷举 12 种）

| 参数 | 取值 |
|------|------|
| 动量窗口 | 20 日、60 日 |
| 调仓频率 | 周度、月度 |
| 动量类型 | 简单动量、双重动量、双重动量+均线过滤 |
| 持仓数量 | `--top_n` 可配，默认 5 |

## 动量计算

### 简单动量

```
动量分数 = (close / shift(close, 窗口)) - 1
```

按动量分数降序排列，选前 top_n 名。

### 双重动量

```
相对动量 = 行业ETF收益 - 沪深300同期收益
绝对动量 = 行业ETF收益 > 0
最终资格 = 相对动量排名前 top_n × 2 且 绝对动量 > 0
```

在符合资格的 ETF 中按相对动量取前 top_n 名。

### 双重动量 + 均线过滤

在双重动量的基础上，增加均线过滤条件：

```
均线过滤 = close > MA(close, 20) AND close > MA(close, 60)
最终资格 = 双重动量资格 AND 均线过滤
```

## 风控措施

### 波动率目标管理

```
全市场ETF等权组合近20日年化波动率 → σ_actual
目标波动率 σ_target = 15%
仓位比例 = min(σ_target / σ_actual, 1.0)
```

若实际波动率过高，等比降低所有持仓权重。

### 个股止损

持仓较成本价下跌 ≥ -8% 时，立即平仓该 ETF。止损后资金暂存现金池，下次调仓时重新分配。

### 策略最大回撤止损

策略净值从峰值回撤 ≥ -15% 时，全部清仓转现金。后续每次调仓日检查是否恢复（净值创新高则重新入场）。

### 相关性分散约束

选出的 top N 候选 ETF，计算两两收益率相关性（近 20 日）：

- 若 pair 相关性 > 0.9，保留排名较高的，剔除排名较低的
- 从后续候选中递补，直到达到 top N 数量

### 现金增强

双重动量模式下，若无任何 ETF 同时满足：
- 绝对动量 > 0
- 排名在前 top_n × 2
- 均线过滤（若启用）

则 100% 持有现金，等待下次调仓。

### 分批调仓

每次调仓信号触发时：
- 第 1 批（调仓日）：执行 50% 仓位调整
- 第 2 批（调仓日 + 3 交易日）：执行剩余 50%

## 回测引擎

### 调仓逻辑

1. 到达调仓日时，计算当前所有候选 ETF 的动量分数
2. 依次应用风控过滤（现金增强 → 均线过滤 → 相关性分散）
3. 选取得分最高的 top_n 只 ETF
4. 按等权分配资金（受波动率目标调整）
5. 分批执行调仓

### 交易假设

- 以收盘价成交
- 不考虑印花税和佣金（可配置）
- 单边滑点 0.1%（可配置）
- 资金可部分持有现金（不计利息）

### 绩效指标

| 指标 | 计算方式 |
|------|----------|
| 年化收益率 CAGR | (终值/初值)^(252/交易日数) - 1 |
| 年化波动率 | 日收益率标准差 × sqrt(252) |
| 夏普比率 | (CAGR - 无风险利率) / 年化波动率 |
| 最大回撤 | max(1 - 净值/净值前高) |
| 卡玛比率 | CAGR / 最大回撤 |
| 胜率 | 盈利交易日数 / 总交易日数 |
| 交易次数 | 调仓触发的总交易笔数 |
